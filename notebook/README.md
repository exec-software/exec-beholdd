# Beholdd project notebook

This notebook documents Beholdd's design rationale and measurement practices.
It is self-contained and uses ordinary Markdown links. Start with the
[index](Index.md); implementation status and reproducible qualification records
are maintained in [the roadmap](../ROADMAP.md) and [research documentation](../docs/research/README.md).

## Publishing notes

Use public model identifiers, exact artifact revisions, relevant hardware
specifications and explicit qualification limits. Do not include credentials,
private network addresses, user-specific filesystem paths, raw chat transcripts,
machine identifiers or unrelated project material.

A note should state its question, method, evidence, limitations and next step.
No external template repository, identifier mapping or private notebook is
required.
